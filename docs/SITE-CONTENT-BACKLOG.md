# DE BOUW PRO — материалы и доработка страниц

Обновлено 27 ноября 2026. Рабочий список для Test. Отмечаем готовность после проверки текста, материалов и страницы в Test.

## Сначала собрать

1. **Graafwerk.** Кадр мини-экскаватора горизонтально для обложки. В первую очередь проверить проект Кати и Ива в Dropbox, где, по словам владельца, есть техника. Для галереи собрать кадры траншеи или котлована, выравнивания участка, обрезки на высоте и вывоза веток. При нехватке попросить фотографии у коллеги.
2. **Vloerverwarming.** Крупные планы фрезерованных каналов, уложенных труб, электрического мата или инфракрасной плёнки и открытого контура тёплой стены до отделки. Плюс готовый пол или стена из того же проекта, если есть пара.
3. **Portfolio.** Подобрать пары «до / после» одного помещения, желательно с близкого ракурса. Для каждого набора зафиксировать тип работ, город, что сделано компанией и разрешение на публикацию.

| Страница                       | Что проверить перед выпуском                                                             |

| `/privacy/`                    | Подтвердить реквизиты, сроки хранения, подключённые сервисы и правила обработки фото.    |
| `/cookies/`                    | Повторить проверку запросов, cookies и браузерного хранилища после изменений интеграций. |
| Страница 404                   | Проверить переходы на главную и к услугам после изменения меню.                          |

Для каждого фото фиксируем источник, город, вид работ, право на публикацию и подходящий кадр для телефона. В публичных подписях используем тип проекта и город. При обработке приводим баланс белого и экспозицию к общей тёплой гамме, сохраняя геометрию помещений и фактический результат работ. Иллюстрации и фотографии поставщиков подписываем по их назначению.
